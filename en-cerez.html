Cookie policy

Last updated: 29 October 2026

elsewhereacademics.com does not use cookies. There are no ads or tracking tools on the site. Fonts, flags and images load from the site's own files.

We use Cloudflare Web Analytics to see how many people visit which pages. According to Cloudflare, this tool does not use cookies or browser storage (localStorage) and does not try to identify visitors by IP address or browser details. It only shows us aggregate statistics such as page views.

GitHub, which hosts the site, records visitors' IP addresses for security. Information about this is in the KVKK privacy notice.

If this changes, we will update this page. For your questions: hello@elsewhereacademics.com
